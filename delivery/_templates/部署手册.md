# studio-erp 部署手册（v2.2）

平面设计公司内部业务管理系统 · 订单 — 收款 — 业绩 — 工资一体化。
前后端已合并为**单个 jar**，一个端口对外服务，不需要 Nginx。

## 二、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11 或 Windows Server 2016+ | 脚本为 .bat |
| JDK | **17**（Temurin / Oracle 均可） | 装完设置 `JAVA_HOME`，`java -version` 能输出 17.x |
| MySQL | **8.0.x** | 需常驻，建议装成 Windows 服务 |
| 内存 | ≥ 4GB（程序占 0.5~1GB） | 并发 ≤ 50 人 |
| 磁盘 | ≥ 20GB（稿件占大头） | 上传上限 50MB/文件 |

## 三、首次部署（约 15 分钟）

### 1. 装 JDK 17
安装后确认：
```cmd
java -version
```
输出 `openjdk version "17.x"` 即 OK。若提示找不到命令，把 JDK 的 `bin` 目录加进系统 PATH。

### 2. 装 MySQL 8.0 并建库
把 MySQL 装成 Windows 服务（安装版默认如此），然后执行建库脚本：
```cmd
mysql -uroot -p < sql\01_create_database.sql
```
> 脚本里应用账号 `studio` 的密码是占位值 `ChangeMe@2026`，**打开文件先改掉**，改完再执行。

### 3. 写配置
```cmd
copy config.env.example config.env
notepad config.env
```
至少填写 4 项：`DB_HOST` / `DB_USER` / `DB_PASSWORD` / `DB_NAME`，
以及可选的 `ADMIN_INIT_PASSWORD`（首次启动建管理员用）。

> 密码不要含 `& ^ % "`，Windows 批处理会解析失败。

### 4. 启动
双击 **start.bat**。脚本会：
1. 读取 `config.env`
2. 最小化窗口启动程序
3. 轮询端口直到就绪（最多 60 秒）
4. 自动打开浏览器 `http://127.0.0.1:8080`

首次启动会自动执行数据库迁移（Flyway V1→V10），建 30+ 张表，约 20~40 秒。

### 5. 登录并改密
- 如果配置了 `ADMIN_INIT_PASSWORD`：用 `admin` + 该密码登录，**立即改密**
- 未配置：由已有管理员在「员工管理」里建号；库里没有管理员时程序只告警不建号

### 6. 局域网访问
其他同事访问 `http://<服务器内网IP>:8080`。
查 IP：`ipconfig`。若访问不通，检查 Windows 防火墙是否放行 8080 端口：
```cmd
netsh advfirewall firewall add rule name="studio-erp 8080" dir=in action=allow protocol=TCP localport=8080
```

## 四、日常运维

| 操作 | 方法 |
|---|---|
| 启动 | 双击 `start.bat` |
| 停止 | 双击 `stop.bat`（按进程名精确匹配，不误杀其他 Java 程序） |
| 查日志 | `logs\studio-erp.log`，按天滚动，单文件 10MB，保留 14 天 |
| 看是否在跑 | 任务管理器找 `java.exe`，或浏览器打开 `http://127.0.0.1:8080` |
| 改端口 | 改 `config.env` 里的 `SERVER_PORT`（如 8090），重启生效；启动脚本会把端口显式传给程序，不受机器上其他环境变量干扰 |
| 开机自启 | 见下方「开机自启」 |

### 开机自启（可选）
把 `start.bat` 的快捷方式放进：
```
C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp
```
注意：这种方式需要用户登录后才启动。服务器无人值守建议用「任务计划程序」，
触发器选「计算机启动时」，操作选 `start.bat`，并勾选「不管用户是否登录都运行」。

## 五、备份（重要）

需要备份两样东西，缺一不可：

1. **数据库**
```cmd
mysqldump -ustudio -p --single-transaction --routines studio_erp > backup_%date:~0,4%%date:~5,2%%date:~8,2%.sql
```
建议每天自动跑一次，保留最近 30 天。

2. **稿件文件** `data/uploads/` 整个目录
数据库里存的是文件路径，文件丢了点下载会提示「文件已丢失」。
直接复制目录即可（停机复制最稳妥，或使用 robocopy 增量同步）。

> 恢复顺序：先建库 → 导入 sql → 放回 uploads → 启动程序。

## 六、升级版本

1. `stop.bat` 停止服务
2. 备份数据库（见上）
3. 用新的 `app\studio-erp-1.0.0.jar` 覆盖旧文件
4. `start.bat` 启动

数据库结构变更由 Flyway 自动执行，**不要手工改表结构**，否则下次启动会校验失败。
升级前若版本跨度大，先看新版 `docs/接口清单.md` 里的变更说明。

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击 start.bat 闪退 | 用 cmd 进目录执行 `start.bat` 看报错；多为未装 JDK 17 或 `config.env` 未创建 |
| 提示「端口未就绪」 | 看 `logs\studio-erp.log`：`Access denied` = 数据库密码错；`Communications link failure` = MySQL 没启动或 IP/端口不对 |
| 页面打不开但程序在跑 | 本机试 `127.0.0.1`；局域网试防火墙 |
| 登录提示「请 15 分钟后再试」 | 密码连错 5 次触发锁定，等 15 分钟或由管理员重置密码 |
| 上传稿件报错 | 检查 `data/uploads` 是否有写权限、磁盘是否满 |
| 数据库迁移校验失败 | 有人手工改过表，或改过已应用的迁移脚本；联系开发处理，**不要**删 `flyway_schema_history` |
| 中文日志乱码 | start.bat 已设 UTF-8；若仍乱码，确认终端代码页为 65001（`chcp 65001`） |

## 八、安全清单（上线前逐项确认）

- [ ] `sql/01_create_database.sql` 里的应用账号密码已改成强密码
- [ ] `config.env` 里 `DB_PASSWORD` 与上一步一致，且该文件未被提交到 Git
- [ ] 管理员初始密码已修改，未继续使用 `ADMIN_INIT_PASSWORD`
- [ ] MySQL 不对公网开放（只监听内网 / 绑定 127.0.0.1 或内网 IP）
- [ ] 程序通过内网访问，未直接映射到公网
- [ ] 数据库备份任务已配置并验证过恢复
- [ ] `data/uploads` 已纳入备份

## 九、技术参数（排障参考）

| 项 | 值 |
|---|---|
| 后端 | Spring Boot 3.2.5 + MyBatis-Plus 3.5.7 + Sa-Token 1.38 |
| 数据库迁移 | Flyway，脚本在 jar 内 `db/migration`（V1~V10） |
| 前端 | Vue 3 + Element Plus，hash 路由（URL 带 `#/`），静态资源打在 jar 内 |
| 登录令牌 | 请求头 `studio-token`，8 小时过期 |
| 分页 | 列表接口 `pageNum`/`pageSize`，单页上限 200 条；导出上限 5000 行 |
| 上传上限 | 单文件 50MB，单请求 51MB |
| 文件存储 | 本地磁盘 `data/uploads`（可在 config.env 之外用 `UPLOAD_DIR` 覆盖） |
